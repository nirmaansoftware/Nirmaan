# Definition of done · IMPLEMENTED (as the review checklist)

A feature is done only when:

- [ ] The UX is complete: empty, loading, error and success states
- [ ] It works end to end
- [ ] Input is validated server-side, and errors are handled and explained
- [ ] Permissions are checked on the server (capability, not role name)
- [ ] Tests pass, including the case that must fail
- [ ] It works at phone width, with no horizontal scroll
- [ ] Accessibility: labels, focus, contrast, keyboard use
- [ ] Docs updated (and the status label in `/docs`)
- [ ] Observable where it matters (audit, activity, usage ledger)
- [ ] Typecheck, lint and build are clean; it deploys

A website also has to pass the [launch list](list.md) before it goes live.
