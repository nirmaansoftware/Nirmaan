# Why Nirmaan gets better over time (moat) · PROPOSED strategy, partly IMPLEMENTED foundations

The moat is **not** "we use AI"; everyone will. It's what accumulates:

```text
Client problems → structured requirements → solutions → implementation data
→ reusable components → engineering knowledge → better agents → faster delivery → better economics
```

| Asset | Captured by | Status |
|---|---|---|
| A library of real problems, in customers' words, with how they were understood | Leads + typed discovery items | IMPLEMENTED |
| Which assumptions were right or wrong | Confirmed/rejected discovery items | IMPLEMENTED |
| Requirement → solution → proof chains | Knowledge graph + evidence | IMPLEMENTED |
| Estimate versus actual by project type | Proposal economics (+ actuals in Phase 3) | Partly |
| Reusable components with usage history | IP library | IMPLEMENTED in the OS; no client uses recorded yet |
| Agent quality history | Eval + human acceptance rates | Partly |

Each project makes the next estimate more accurate, the next build shorter,
and the next agent run better grounded. That compounding is the moat.
